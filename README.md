# 🛒 E-commerce Power BI Dashboard

## 📊 Overview
Interactive 3-page dashboard built for DTC brands to track revenue, customer behavior, and product performance.

## 🚀 Features
- **Executive Summary**: Revenue, Orders, AOV, New vs Returning Customers
- **Customer Insights**: RFM segmentation, CLV by cohort, top cities
- **Product Performance**: BCG matrix (Stock vs Sales), top 10 products, sell-through KPIs

## 🛠️ Tech Stack
- Power BI (DAX, Star Schema)
- Python (pandas, data cleaning)
- SQL (joins, ETL)

## 📁 Files
- `dashboard.pbix` - Main Power BI file
- `*.pdf` - Executive reports
- `clean_ecommerce_tables.py` - Python cleaning script
- `inventory.csv` - Sample stock data

## 📈 Results
- Identified 14% "Champion" customers driving 60% revenue
- Flagged 23 "Restock Alert" products preventing $15K stockouts
- Reduced manual reporting time by 70%
